# Rozaliia Nabiullina Portfolio

An English-language static portfolio with two independent controls: a professional focus switch (ML Engineer or Research Scientist) and a layout switch (simple resume or visual portfolio). The simple layout is the default. Sections follow the supplied ML Engineer CV. The download button serves an unchanged copy of that DOCX.

Live site: https://rosali3.github.io/portfolio/

## Publication images

The visual layout presents one publication at a time in a looping sliding gallery, with keyboard and touch navigation. The eLIBRARY paper includes Figure 2 extracted from the PDF supplied by the author. The simple layout presents all publications as text.

## Publishing

Push changes to `main` in https://github.com/rosali3/portfolio. GitHub Actions publishes the site. No build step is required.

The downloadable DOCX is the author's unmodified upload. It includes details that are intentionally omitted from the webpage. Earlier repository history may retain an older DOCX; removing historical references requires a separate cleanup.
