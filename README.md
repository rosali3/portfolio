# Портфолио Розалии Набиуллиной

Статический адаптивный сайт на русском языке. Переключатель профиля меняет описание, акценты опыта, дополнительный исследовательский проект и объём списка публикаций. Отдельный переключатель меняет официальную белую и розовую тему с блёстками. Оба выбора сохраняются в браузере. Исходный DOCX и простая текстовая версия для ATS доступны для скачивания на сайте.

У публикаций размещены изображения из семи доступных работ: рисунки из пяти открытых международных статей и первые страницы двух русскоязычных статей. У записи eLIBRARY изображение не добавлено: полный текст недоступен, поэтому необходим оригинальный PDF. Подписи указывают источник и тип изображения, а рисунки CC BY сохранены без изменений.

## Просмотр

Откройте `index.html` в браузере. Для локального сервера: `npx serve .`.

## GitHub Pages

Репозиторий: https://github.com/rosali3/portfolio. Сайт: https://rosali3.github.io/portfolio/.

При изменении файлов в ветке `main` workflow `.github/workflows/pages.yml` публикует сайт автоматически. Источник в **Settings → Pages** — **GitHub Actions**.

Сборка не требуется. Все пути относительные, поэтому сайт работает и в репозитории вида `username.github.io`, и в проектном репозитории.

Контент перенесён из предоставленного резюме. Проверьте актуальность дат и персональных контактов перед публикацией.
